# 진표의 국어 대결

7살 진표를 위한 국어 보드게임. 말썽이(도깨비)와 주사위 말판 대결을 하면서
초등 1~4학년 국어 문제를 푸는 웹 게임입니다.

- 정답을 맞히면 주사위를 굴려 그만큼 전진, 틀리면 한 칸만 이동
- ⭐별칸 · 🚀로켓칸 · 🌀미끄럼칸 · 🎁선물칸 · ⚡번개칸 · 🍀한번더칸
- 아이템: 🎲황금주사위 · 🛡️방패 · 💡힌트
- 5개 왕국(난이도): 한글 마을(초1) → 맞춤법 숲(초2) → 낱말 호수(초3) → 속담 산(초4) → 이야기 성(초4+)
- 문제를 한국어 음성으로 읽어 줍니다
